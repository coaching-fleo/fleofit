# Team di atleti e sfida interna — piano di implementazione

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** il coach crea team di suoi atleti; l'atleta entra solo accettando un invito
(notifica + push); ogni allenamento di team è una sfida col risultato inserito
dall'atleta, ordinata per metrica, con il testa a testa nei team da due.

**Architecture:** quattro tabelle nuove e additive (`team`, `team_membri`, `team_sfide`,
`team_risultati`) con RLS e un trigger che impone le transizioni di stato (il coach non
scrive mai `dentro`). Una funzione `team_scheda(uuid)` serve i nomi dei compagni, perché
l'atleta legge solo la propria riga di `athletes`. Il calcolo della sfida è puro
(`src/lib/sfidaTeam.js`); le pagine sono pigre e stanno dietro l'interruttore `team` di
`funzioni_app`, spento alla partenza come le Scarpe.

**Tech Stack:** React 19, React Router 7, Tailwind 4 (token di `src/index.css`), Supabase
(Postgres + RLS + Edge Function Deno), Vitest + jsdom, Capacitor 8 (iOS e Android).

**Spec:** `docs/superpowers/specs/2026-11-06-team-design.md`

## Global Constraints

- 🔒 **Il Task 1 scrive la migrazione ma NON la applica.** Si applica a mano dal SQL editor
  solo dopo il sì esplicito del committente (CLAUDE.md, 0-bis: decima eccezione). Fino ad
  allora l'app deve funzionare **senza** le tabelle: lettura fallita = funzione assente,
  nessun alert (stesso comportamento di `scarpaCompletamento.js`).
- Interruttore: riga `('team', 'spenta')` in `funzioni_app`; pagine dentro
  `<SoloSeAccesa nome="team">`, ingressi dietro `useFunzione('team')`.
- Si lavora su `app`. Mai push su `main` (CLAUDE.md §1.1). Commit con i file **per nome**.
- Testi dell'interfaccia in italiano. Colori solo dai token (`bg-brand`, ecc.), aptica solo
  dai sei verbi di `src/lib/aptica.js`, niente `alert()`/`confirm()` (usare
  `CustomAlert`/`CustomConfirm`), modali con `createPortal(…, document.body)`.
- Nessun dato mancante come zero: un risultato assente è «—».
- Pagine nuove con `lazy()` in `src/App.jsx`; `index` non deve crescere oltre ~1 KB
  (misura col `npm run build` prima e dopo, CLAUDE.md §2). Niente import statici di
  `sfidaTeam.js` o `teamDb.js` da `Home.jsx` o `RpeModal.jsx`.
- localStorage solo con `leggiJson`/`scriviJson` di `src/lib/offlineQueue.js`.
- Ogni test nuovo si vede **fallire** prima (romperne apposta il codice), poi passare.
- Valori fissati qui (la spec li lasciava al piano):
  - attesa del reinvito: **3 giorni** (`GIORNI_REINVITO = 3`);
  - tetti di `valore`: tempo ≤ **86400** s, ripetizioni ≤ **10000**, kg ≤ **100000**,
    distanza ≤ **1000000** m; sempre `> 0`;
  - verso: `tempo` → `minore`, le altre → `maggiore`;
  - app vecchia sugli Store: **nessun blocco**; il coach vede «In attesa da N giorni»;
  - ingressi: coach → riga «Team» in Impostazioni › Solo coach (accanto a «Catalogo
    scarpe») e bottone nella testata di Atleti; atleta → riga «I miei team» in Impostazioni.
    (La spec diceva «Profilo»: per l'atleta il posto delle funzioni con l'interruttore è
    Impostazioni, come le Scarpe.)
- Rotte: `/team`, `/team/:id`, `/team/:id/sfida/:sfidaId`, `/team/invito/:id`.

## Review Focus

1. **Atleta spostato a un altro coach con un invito pendente** → l'invito non si vede e non
   si può accettare (`e_mio_coach(team.coach_id)` falso). Test SQL nel Task 1.
2. **Sfida creata quando un membro è ancora `invitato`** → il workout va solo ai `dentro`; chi
   entra dopo non riceve la sfida già creata. Test in `teamDb.test.js` (Task 5).
3. **Risultato `mm:ss` scritto male** («1:75», «90», «») → `leggiValore` restituisce `null`
   e il bottone resta spento; «90» per il tempo vale 90 s. Test in `sfidaTeam.test.js` (Task 2).
4. **Doppio tocco su «Accetta» o rete giù** → una sola transizione; in errore lo stato resta
   `invitato` e compare `CustomAlert`. Test in `InvitoTeam.test.jsx` (Task 4).
5. **Push toccata con le tabelle non ancora applicate o la funzione spenta** → `/team/invito/:id`
   rimanda alla Home senza schermo bianco. Test in `InvitoTeam.test.jsx` (Task 4).

  - `versoDi(metrica) → 'minore'|'maggiore'`

  - `puoReinvitare(risposto_il: string|null, adesso: Date) → boolean`
